# 分子构建器 — 用户手册

**版本**：0.1.0
**日期**：2026-09-13

本手册面向使用分子构建器绘制有机分子结构式的用户，介绍界面、操作流程与常见问题。

---

## 1. 产品简介

分子构建器是「有机化学反应工作台」的输入模块。它从一条默认的乙烷线出发，让你通过**点选原子或键**逐步搭建分子，并实时给出分子式、中英文名称、SMILES / InChI / InChIKey，支持一键整理为规范结构式、保存到本地分子库、导出论文级矢量图。

**适用**：烷、烯、炔、醇、醛、酮、羧酸、酯、醚、胺、苯系物等常见有机分子。
**不适用**：聚合物、生物大分子、金属有机配合物。

---

## 2. 安装与运行

需要 Node.js 18 及以上。

```bash
npm install      # 安装依赖，并自动复制 RDKit wasm 到 public/rdkit
npm run dev      # 启动开发服务器，浏览器打开 http://localhost:5173
```

生产构建与预览：

```bash
npm run build    # 生成静态产物到 dist/
npm run preview  # 本地预览生产产物
```

> 首次打开时，右下角状态栏会显示「引擎: RDKit 加载中…」，加载完成变为「引擎: RDKit ✓」。若显示「引擎: 自研兜底」，功能仍可正常使用，只是部分描述符由自研引擎计算。
