# 有机化学反应工作台 — 用户手册

**版本**：0.2.0
**日期**：2026-09-18

本手册面向使用本工作台的用户，介绍两个模块的界面、操作流程与常见问题：

- **分子构建器**：绘制单个有机分子结构式（第 3–11 章）
- **反应模块**：组合反应式、配平、预测产物、导出（第 12 章）

---

## 1. 产品简介

本工作台从一条默认的乙烷线出发，让你通过**点选原子或键**逐步搭建分子，并实时给出分子式、中英文名称、SMILES / InChI / InChIKey；在反应模块中可把多个分子组合成反应式、按化学规范配平、依据内置规则库预测候选产物，并导出论文级矢量图与标准化学文件。

**适用**：烷、烯、炔、醇、醛、酮、羧酸、酯、醚、胺、苯系物等常见有机分子，以及中学/大学有机化学主干反应与常见合成反应。
**不适用**：聚合物（仅作聚合提示）、生物大分子、金属有机配合物、逆合成路线规划。

---

## 2. 安装与运行

需要 Node.js 18 及以上。

```bash
npm install      # 安装依赖，并自动复制 RDKit wasm 到 public/rdkit
npm run dev      # 启动开发服务器，浏览器打开 http://localhost:5173
```

生产构建与预览：

```bash
npm run build    # 生成静态产物到 dist/
npm run preview  # 本地预览生产产物
```

> 首次打开时，右下角状态栏会显示「引擎: RDKit 加载中…」，加载完成变为「引擎: RDKit ✓」。若显示「引擎: 自研兜底」，功能仍可正常使用，只是部分描述符由自研引擎计算。

## 4. 快速开始：画一个乙醇

1. 打开应用，画布中央显示一条线——这是默认的**乙烷**，两端是看不见的碳原子。
2. **点选**右端（线的右端点附近），出现工具条：`＋ 增加` `⇄ 替换` `⌁ 连接` `× 删除`。
3. 点击 `＋ 增加`，在弹出菜单的「增加基团」中点 `OH`。
4. 结构变为 `CH₃—CH₂—OH`。右面板「中文名」显示 **乙醇**，分子式显示 `C2H6O`。
5. 点击右面板下方的 **保存到分子库**，结构即被收藏。

## 5. 操作指南

### 5.1 点选原子

在画布上**单击**任意原子，其旁出现工具条：

| 按钮 | 作用 |
|------|------|
| `＋ 增加` | 从该原子生长出新键、原子或基团 |
| `⇄ 替换` | 把该原子替换为其他元素或基团（保留原有连接） |
| `⌁ 连接` | 以该原子为起点，再点另一个原子即可成键（用于成环） |
| `× 删除` | 删除该原子 |

> 只**悬停**不会出现工具条，需**单击**才会弹出，避免误触。

### 5.2 增加结构

点击 `＋ 增加` 后，菜单分三组：

1. **增加键**：单键 / 双键 / 三键。选择后在原子对面自动生成一个**隐形碳端点**并按标准键角放置。
   - 例：乙烷右端加单键 → 丙烷。
2. **增加原子**：`H O N S P F Cl Br I`。以单键连接新原子，新原子作为可见端点（显示元素符号）。
3. **增加基团**：`OH`（羟基）`NH2`（氨基）`CH3`（甲基）`COOH`（羧基）`CHO`（醛基）`NO2`（硝基）`SO3H`（磺酸基）`Ph`（苯基）。基团整体接入，内部按标准结构式排布（`Ph` 为正六边形苯环）。

### 5.3 替换

点击 `⇄ 替换`，选择目标原子或基团：

- 原有连接键**保留**，只是所连的原子/基团发生变化。
- 例：乙烷右端替换为 `OH` → 乙醇。
- 若替换会导致价键超限，操作被拒绝并提示，相关原子会高亮。

> 也可以在**右面板**选中原子后，用「快速替换为」按钮区直接替换，无需回到画布。

### 5.4 连接成环

1. 单击起点原子，点 `⌁ 连接`。
2. 再单击要连接的目标原子。
3. 在弹出菜单中选单键 / 双键 / 三键。

若两原子之间已有键，或起点与终点是同一原子，会被拒绝并提示。

### 5.5 编辑键

单击任意键，出现键工具条：

| 按钮 | 作用 |
|------|------|
| `单键` / `双键` / `三键` | 切换键级 |
| `× 删除` | 删除该键 |

**芳香环（苯环）特例**：对苯环上的键点击键级按钮，会将**整圈**实体化为单双交替的凯库勒结构，并把所选键设为对应键级，便于继续编辑。工具条上会标注「芳香环」。

### 5.6 删除

**删除原子**：

- **非碳原子**：视为「替换为碳」，保留原有连接，不删除相邻结构。
- **碳原子**：
  - 无连接键 → 直接删除该原子；
  - 只有 1 个连接键 → 删除该碳与其键，对侧原子成为新端点；
  - 有 2 个或以上连接键 → 弹出对话框，按方位选择「保留左侧 / 右侧 / 上方 / 下方 / 左上 / 右上 / 左下 / 右下」，未保留一侧的结构会被删除。

**删除键**：

- 若为**环内键**：仅断开该键（开环），不删除任何原子；
- 若为**普通键**：弹出对话框选择保留哪一侧，未保留一侧会被删除，保留侧成为新端点。

**若删除导致分子为空**：自动重置为默认乙烷，并给出提示。

### 5.7 移动原子

按住任意原子拖动即可移动它。移动距离小于 3px 视为点击，不会产生位移，也不占用撤销记录。

## 6. 自动整理布局

点击左侧「布局」区的 **自动整理布局**，系统会按化学规范重新排布：

- 环系取正多边形（苯环为正六边形）；
- 链与取代基按杂化态取标准键角（sp³ 109.5° / sp² 120° / sp 180°）；
- 键长归一、非键合原子间距优化，避免线条堆叠交叉；
- 多片段水平等距排布；
- 整体质心保持不变，画面不会跳动。

> 整理**只改变坐标**，不改动任何原子、键与键级。

点击 **布局参数 ▼** 可展开调节：

| 参数 | 范围 | 说明 |
|------|------|------|
| 键长 | 30–70 | 标准键长（像素） |
| 原子间距 | 40–120 | 原子最小间距 / 片段间隔 |
| 主链方向 | 水平 / 30° / 60° / 垂直 | 主链对齐方向 |
| 按主轴自动对齐 | 开 / 关 | 是否自动旋转主链到指定方向 |

调整后再次点击「自动整理布局」生效；「恢复默认参数」可还原。

## 7. 视图开关

在左侧「视图」区：

- **显示 C-H 氢**：开启后，碳上的氢以显式 H 端点渲染（默认隐藏）。
- **显示原子编号**：开启后在原子上显示编号，便于核对。

> 官能团氢（-OH、-NH₂、-SH、-CHO 的甲酰氢、端炔 -C≡C-H）**不受开关影响，始终显示**；切换开关不会修改分子数据。

## 8. 命名与标识符

右侧属性面板显示：

- **分子式**、**重原子数**、**验证状态**；
- **中文名** / **IUPAC 名**：自动命名结果，均可**手动编辑**（超出自动命名范围时自行填写）；
- **SMILES / InChI / InChIKey**：**点击即可复制**到剪贴板。

命名在每次结构变化后约 0.3 秒自动更新；拖动原子不会触发重算。

验证状态含义：

| 状态 | 含义 |
|------|------|
| 校验通过 | 名称、SMILES、InChIKey 均齐备 |
| 部分计算（命名缺失） | 有 SMILES，但命名未能确定，可手动输入 |
| 命名失败，可手动输入 | 无法生成 SMILES，请检查结构 |
| 计算中… | 正在计算 |

## 9. 分子库

- **保存**：点击右面板「保存到分子库」，按 **InChIKey**（或 SMILES）去重；若已存在，提示「该结构已在库中」。
- **查看**：点击顶栏或左面板的「分子库」打开列表，显示名称、分子式、InChIKey。
- **载入**：点击条目「载入」，结构回到画布。
- **删除**：点击条目「删除」将其移出分子库。

分子库保存在**当前浏览器本地**（localStorage），清除浏览器数据会一并清除。

## 10. 导出

左侧「导出」区：

| 格式 | 说明 | 文件名 |
|------|------|--------|
| **SVG** | 矢量图，可直接插入论文/专利，缩放不失真 | `分子结构.svg` |
| **PNG** | 位图，3 倍分辨率、白底 | `分子结构.png` |
| **MOL** | V2000 molblock，可被 ChemDraw、Marvin、RDKit 读取 | `分子结构.mol` |
| **SMILES** | 文本文件，首行 canonical SMILES，次行名称/分子式 | `分子.smi` |

导出内容**不含**透明热区与画布缩放变换，仅含结构本身并自动留白。

## 12. 反应模块

点击顶栏的 **分子构建器 / 反应** 切换顶层视图。反应模块用于把多个分子组合成反应式、按化学规范配平、预测候选产物，并导出标准格式。

### 12.1 界面概览

```
┌──────────────────────────────────────────────────────────────┐
│ 有机化学反应工作台   [分子构建器] [反应]            [分子库]    │
├──────────────┬──────────────────────────────┬────────────────┤
│ 组入组分      │     反应物 + … + 反应物       │  箭头与条件      │
│ · 当前分子    │          ──[条件]──▶          │  配平            │
│ · 从分子库    │          产物 + … + 产物       │  组分属性        │
│ 试剂与条件库  │                              │  导出            │
│ · 试剂库      │                              │  外部预测服务     │
│ · 条件预设    │                              │                │
│ 反应预测      │                              │                │
│ 反应式操作    │                              │                │
└──────────────┴──────────────────────────────┴────────────────┘
```

### 12.2 组入组分

- **当前分子 → 反应物 / 产物**：把分子构建器里正在编辑的分子加入反应式。
- **从分子库组入**：左面板列出分子库条目，每条都有「→ 反应物」「→ 产物」按钮。
- **双击组分卡片**：把该组分载回分子构建器编辑（右上角会切到分子构建器）。
- 卡片上的 **系数按钮**：点击可改计量系数，右键还原为 1。
- 卡片下方 **▶ / ◀**：把组分在反应物侧与产物侧之间移动；**×** 移除该组分。

### 12.3 试剂与条件

试剂是写在箭头上的反应条件，**不参与配平**。

- **试剂库**：78 条常用试剂，支持按名称 / 英文名 / 缩写 / 标签检索，按酸、碱、氧化剂、还原剂、催化剂、溶剂等分类筛选。点击条目即插入为试剂。
- **条件预设**：常见的成套反应条件（如「Fischer 酯化」「卤代烃水解」「卤代烃消去」），点击即一键填充到箭头条件。
- 试剂与条件会自动合成箭头上方/下方文字。**一旦你手动改写过箭头文字，就不再自动同步**（避免覆盖你的输入）；可用「按条件重新生成箭头文字」恢复同步。
- 右侧面板提供结构化的温度 / 溶剂 / 催化剂 / 时间 / 气氛字段。

> 注意「NaOH 水溶液」与「NaOH 醇溶液」是**两个独立条目**——它们决定卤代烃是水解成醇还是消去成烯烃。同理，醇在 140 ℃ 与 170 ℃ 走不同路径，请填对温度。

### 12.4 配平

- 两侧都有组分后，工具栏与右面板会实时显示元素守恒情况，并**逐元素**列出 `C 4=4 ✓`、`H 8=8 ✗` 这样的明细。
- 点击 **一键配平**：系统求解元素守恒线性方程组，给出**最小正整数系数**。系数由方程解出，不是硬编码（例如「苯 + 3H₂ → 环己烷」的 3 是算出来的）。
- 存在多组解时会提示「存在多组配平方案」，给出系数和最小的一组，可手动调整。
- 不守恒时提示「原子不守恒，无正整数配平方案」并列出差异元素。
- 未配平不影响出图与导出，只影响系数显示（方程式中系数以 `?` 表示）。

### 12.5 反应预测

点击 **按规则预测产物**。预测基于**本地规则库**（66 条规则，覆盖烯、炔、芳烃、卤代烃、醇、酚、醛酮、羧酸酯、油脂、糖类、氨基酸与蛋白质），无需联网。

结果按三类**分区展示**，这是理解本功能的关键：

| 分区 | 含义 | 可做的操作 |
|------|------|-----------|
| **结构候选** | 能给出确定产物结构 | 「采纳为产物」写入产物侧；「插入画布」送到分子构建器继续编辑 |
| **典型性质与现象** | 鉴别现象或整体性质，**没有可画的结构** | 「复制结论」；不写入产物侧、不参与配平 |
| **聚合提示** | 聚合物，聚合度 n 是变量 | 「插入重复单元到画布」；**不参与配平** |

**为什么必须分三类**：像「FeCl₃ 显紫色」「蛋白质遇浓硝酸变黄」是鉴别现象，本就没有产物结构；聚合反应的聚合度 n 无法用固定系数配平。若强行编造结构，等于伪造化学结论。因此这三类在界面上分开呈现。

每条候选都会说明**命中了哪条规则、作用在哪些原子上**（命中的原子会在反应物卡片上高亮）、以及排序依据。界面措辞一律是「候选」「建议」而非「预测结果」——排序是启发式打分，不是概率。

若提示「元素未完全守恒（如 H 少2）」：这通常是因为**试剂参与成键**（H₂、H₂O、X₂、HX 等），其原子进入了产物但试剂本身写在箭头上而非反应物侧。这是预期行为，可按提示把对应试剂也加入反应物侧以完成配平。

### 12.6 导出

| 格式 | 说明 |
|------|------|
| **SVG** | 矢量反应式，可直接用于论文 |
| **PNG** | 3 倍分辨率位图，白底 |
| **PDF** | 由浏览器打印生成。在弹出的打印对话框中选择「另存为 PDF」即可；**中文可选中、可搜索** |
| **RXN** | RXN V2000，可被 RDKit / ChemDraw / Marvin 读取（系数以重复 molblock 表达） |
| **SMILES** | 反应 SMILES `反应物>试剂>产物`。**SMILES 无法表达计量系数**，导出文件会附提示 |
| **化学方程式** | 三种文本变体，见下 |

化学方程式三变体：

| 变体 | 样例 | 用途 |
|------|------|------|
| **下标** | `CH₃CH₂OH + CH₃COOH --[浓H₂SO₄, Δ]--> CH₃COOCH₂CH₃ + H₂O` | 直接粘贴到 Word、课件、试卷 |
| **LaTeX** | `\ce{CH3CH2OH + CH3COOH ->[H2SO4][\Delta] ...}` | 论文与 LaTeX 排版 |
| **ASCII** | `CH3CH2OH + CH3COOH -> CH3COOCH2CH3 + H2O` | 程序处理、纯文本环境 |

> 方程式以**分子式**表达，会丢失结构信息（同分异构体无法区分，如乙醇与二甲醚同为 C₂H₆O）。正式交付建议使用 SVG / PDF。

### 12.7 保存与撤销

- **保存反应式**：存到浏览器本地；**载入上次**可读回。
- 反应式内的坐标与结构一并保存，载入后可直接继续编辑。
- `Ctrl + Z` / `Ctrl + Y`：在反应模式下撤销/重做反应式操作（与分子构建器各自独立）。

### 12.8 外部预测服务（默认关闭）

右面板底部可配置外部预测服务，**默认关闭**。

- 启用后，反应物结构（SMILES）会被发送至你配置的第三方服务——界面会明确提示这一点，请确认其隐私政策与合规要求。
- 需要填写服务地址、密钥与密钥请求头名。密钥仅存于本地浏览器。
- 调用约定（通用 JSON）：请求体 `{ reactants: string[], agents: string[], conditions: {...} }`；响应体 `{ products: [{ smiles: string[], name?: string }] }`。
- **仅当本地规则一条都未命中时**才会调用外部服务；外部结果与本地结果分组展示并标注来源；接口失败时静默降级为「仅本地结果」，不影响使用。

> 之所以做成「用户自备地址」而非内置某家服务：免费且稳定的公开反应预测接口并不存在，硬编码会随对方接口变动而失效。

## 13. 常见问题

**Q：为什么原子是空的，看不到 C 字母？**
A：按化学制图惯例，碳原子不显示字母，仅以键线交点表示。开启「显示原子编号」可辅助定位。

**Q：点击「芳香键」为什么没有？**
A：芳香键不能在非环结构中手动添加。要得到苯环，请用「增加基团 → `Ph`」插入苯基。

**Q：中文名/IUPAC 名显示为空怎么办？**
A：复杂或超出自研命名范围的分子会尝试从 PubChem / CACTUS 在线获取。若无网络或未收录，请直接在名称输入框中手动填写。

**Q：整理布局后我的拖动位置没了？**
A：「自动整理布局」会按化学规范重排全部坐标，这是预期行为。

**Q：结构会不会上传到服务器？**
A：不会。分子与反应数据仅保存在浏览器本地。仅两种情况会联网：① 自研命名失败时用 SMILES 向 PubChem / CACTUS 查询名称；② 你**主动启用**了外部预测服务。

**Q：状态栏显示「引擎: 自研兜底」有影响吗？**
A：RDKit 未能加载（如离线或资源缺失）。分子构建、布局、导出均可正常使用，仅 SMILES/InChI 由自研引擎生成，个别复杂结构的标识符可能不够规范。**反应预测需要 RDKit**，未加载时会提示不可用。

**Q：如何清空当前画布？**
A：点击顶栏或左面板的「重置」回到默认乙烷；或删除到分子为空时系统会自动重置。反应模式下用「清空反应式」。

**Q：预测出的产物一定是正确的吗？**
A：不一定。规则库覆盖的是常见反应类型，产物一律标为「候选」。复杂区域选择性、非常规条件、超出自研命名/匹配范围的结构可能给出不准确或不完整的结果，请以化学判断为准。每条候选都会显示命中的规则与适用条件，便于你核对。

**Q：为什么我把试剂写在箭头上，配平却说元素不守恒？**
A：因为试剂不在反应物侧。例如「烯烃 + H₂/Ni」中 H₂ 的氢原子进入了产物，但 H₂ 写在箭头上，所以按反应物与产物直接比较会出现 H 的差异。把该试剂也加入反应物侧即可正常配平。

**Q：为什么点「PDF」没有直接下载文件？**
A：PDF 走浏览器原生打印（零依赖、矢量保真、中文可选中）。在打印对话框中选择「另存为 PDF」即可。若需要一键落盘，请用 SVG 或 PNG。
