# 分子构建器 — 设计方案

**项目**：有机化学反应工作台 · 分子构建器
**版本**：0.1.0
**日期**：2026-09-13
**文档类型**：系统设计方案

---

## 1. 项目概述

### 1.1 定位

分子构建器是有机化学反应工作台的核心输入模块，用于以**增量式、点选驱动**的方式构建有机分子结构式。构建结果以「原子编号 + 连接键」的图结构存储，可一键整理为符合 IUPAC/ACS 规范排布的 2D 结构式，并实时命名、持久化到本地分子库、导出标准化学文件。

### 1.2 设计理念

| 理念 | 说明 |
|------|------|
| 碳端点为操作核心 | 不依赖原子面板，编辑通过点选已存在的原子/键触发 |
| 默认乙烷起步 | 进入即一条线、两个隐形碳端点，用户从既有结构生长 |
| 结构式即标准 | 键长归一、标准键角、环取正多边形，导出可直接用于论文 |
| 图数据唯一性 | 原子编号 + 连接键存储，正确区分同分异构体 |
| 渲染与数据分离 | 坐标仅属渲染层，编辑逻辑只操作图数据 |
| 渐进增强 | RDKit 可用时提供权威描述符，不可用时自研引擎完整兜底 |

### 1.3 范围

- **支持**：烷、烯、炔、醇、醛、酮、羧酸、酯、醚、胺、苯系物等常见有机分子；H、O、N、S、P、F、Cl、Br、I 等常见元素端点。
- **不支持**：聚合物、生物大分子、金属有机配合物、立体化学编辑（数据结构已预留 `stereo` 字段）。

## 3. 总体架构

### 3.1 分层结构

```
┌──────────────────────────────────────────────────────────┐
│ components/  UI 层（React 组件、SVG 渲染、浮层工具条）      │
├──────────────────────────────────────────────────────────┤
│ store/       状态编排层（Zustand：分子图 / 分子库 / 视图）   │
├──────────────────────────────────────────────────────────┤
│ hooks/       副作用编排（防抖命名管线）                      │
├──────────────────────────────────────────────────────────┤
│ engine/      化学引擎（编辑操作、价键、环、描述符、命名、序列化）│
├──────────────────────────────────────────────────────────┤
│ layout/      布局引擎（几何、自动整理、RDKit 桥接）           │
├──────────────────────────────────────────────────────────┤
│ lib/         基础设施（导出、本地存储、在线命名服务）          │
└──────────────────────────────────────────────────────────┘
                 types/  共享数据模型（唯一事实来源）
```

**依赖方向**：`components → store → engine/layout → lib/types`，单向依赖，engine 与 layout 为纯函数层，不感知 React。

### 3.2 数据流

```
用户交互（点选原子/键）
   ↓
Canvas 组件 → store 的 applyXxx 动作
   ↓
engine 纯函数返回新 MoleculeGraph（不可变）
   ↓
store.commit()：压入历史 + localRelax 键长松弛 + 更新图
   ↓
useMeasure 监听图签名（坐标无关）→ 300ms 防抖 → computeMeasure
   ↓
更新 measure → 右面板 / 状态栏 / 分子库保存
```

关键约束：**拖动坐标不触发命名重算**。命名以「图签名」（原子/键的化学属性串）为依赖，坐标变化被排除。

## 4. 数据模型

沿用 [设计文档 §8](../设计文档.md) 的「原子编号 + 连接键」图模型，落地为 TypeScript 接口（见 `src/types/molecule.ts`）。

### 4.1 关键字段

- **Atom**：`atom_id`（唯一、删除不回收）、`element`、`charge`、`radical`、`implicit_h`、`lone_pairs`、`stereo`、`x/y`（渲染层）、`in_ring`、`manuallyPlaced`。
- **Bond**：`bond_id`、`atom1_id`、`atom2_id`、`order`(1/2/3)、`aromatic`、`stereo`。
- **MoleculeGraph**：`atoms`、`bonds`、`nextAtomId`、`nextBondId`（自增计数器，保证编号稳定）。

> `x/y` 属于渲染层，化学逻辑（命名、分子式、SMILES）完全忽略坐标。详细字段规范见 [协议规范](./协议规范.md)。

### 4.2 不变量

1. 原子/键编号在分子生命周期内唯一且不被回收（删除后 `nextAtomId` 继续递增）。
2. 所有编辑出口统一经 `settle()`：芳香性规范化 → 隐式氢/孤对重算。
3. 每次编辑后校验超价；超价则整笔操作被拒绝并返回错误与高亮原子。

## 5. 核心算法设计

### 5.1 编辑操作（`engine/moleculeOps.ts`）

所有操作均为**纯函数**，输入图、输出新图（不可变），不触碰 React 与命名。

| 操作 | 行为 |
|------|------|
| `addBond` | 在原子对面生成默认隐形碳端点，按所选键级连接 |
| `addAtom` | 单键连接新杂原子端点 |
| `addGroup` | 按模板构建基团碎片（-OH/-NH₂/-CH₃/-COOH/-CHO/-NO₂/-SO₃H/-Ph），整体接入 |
| `replaceAtomElement` | 保留原有连接键，替换元素 |
| `replaceWithGroup` | 移除原原子，原连接键改连到基团连接点 |
| `setBondOrder` | 普通键改键级；芳香键/凯库勒环 → **整圈交替重排** |
| `connectAtoms` | 两个已存在原子直接成键（用于环化），拒绝自连与重复成键 |
| `deleteAtom` | 非碳→视为替换为碳；碳按连接数分流（0/1/≥2 键） |
| `deleteBond` | 环键→仅开环；非环键→保留一侧并清理孤立端点 |

**基团模板几何**：基团内部键角按中心原子方向为基准旋转（如 -COOH 的两个氧相对连接方向 ±60°，-NO₂ 为 ±55°），-Ph 直接生成正六边形（边长 = 键长，芳香键标记）。

### 5.2 价键与隐式氢（`engine/valence.ts`）

- 主价表：C:4，N:3/5，O:2，S:2/4/6，P:3/5，卤素/H:1。
- **芳香环内按 Kekulé 计**：首根芳香键计 2、其余各计 1，使苯环碳恰好为 4 价。
- 隐式氢 = 目标价 − 已用价 − 自由基电子数（下限 0）。
- 超价校验：已用价超过该元素最高价即报错，阻止编辑。

### 5.3 环与芳香性（`engine/ring.ts`）

- **环键判定**：删除该键后两端仍连通 → 环键。
- **最短环**：从键一端 BFS 到另一端（避开自身），可限定仅芳香键参与。
- **芳香性规范化** `normalizeAromatics`：环被破坏后，清理残留芳香标记，并为仍成环的凯库勒环补上交替单双键，保证键级信息不丢失。
- **桥键识别**：用于布局中区分稠合环系与普通环系。

### 5.4 自动整理布局（`layout/arrange.ts`）

同步执行的规则型布局，**只改坐标，化学数据完全不变**：

1. 每个连通分量独立布局；环系按正多边形模板生成（苯环正六边形）。
2. 链与取代基按 BFS 铺设，按杂化态取标准键角（sp³ 109.5° / sp² 120° / sp 180°）。
3. 候选方向以「与已放置原子的最小间距最大化」择优，避免堆叠。
4. 稠合环等非简单环先用原坐标做键长/间距约束松弛，再接入主布局。
5. 按主惯性轴对齐到指定方向（默认水平）。
6. 多片段水平等距排布，整体质心保持不变（避免视图跳变）。

**性能**：邻接表 + 均匀网格近邻查询，整体接近 O(n)，500 原子长链可即时完成（见 `scripts/verify.ts` 压测用例）。

可配置参数：`bondLength`（30–70px）、`spacing`（40–120px）、`direction`（水平/30°/60°/垂直）、`align`（是否按主轴对齐）。

### 5.5 命名管线（`engine/naming.ts`）

```
graph
 ├─ 分子式（本地，即时，不依赖 RDKit）
 ├─ 描述符：RDKit 8s 超时 → SMILES / InChI / InChIKey
 │     └─ 失败兜底：自研 serialize.toFallbackSmiles
 ├─ 英文名：自研 iupac → PubChem（5s）→ CACTUS（5s）
 └─ 中文名：自研 chineseNamer → PubChem 同义词（5s）
```

- 状态：`ok`（名 + SMILES + InChIKey 齐备）/ `partial`（仅 SMILES）/ `failed`。
- 命名失败时右面板名称字段可手动输入。
- 中文在线来源仅取 PubChem 同义词中以化学名后缀结尾、含 CJK 的最短词条，以降低误配。

### 5.6 RDKit 集成（`engine/rdkitLoader.ts` + `layout/rdkitLayout.ts`）

- 通过 `<script>` 注入 `/rdkit/RDKit_minimal.js`，`locateFile` 指向 `/rdkit/*.wasm`。
- 单例 + 状态发布（idle/loading/ready/failed），10s 初始化超时；失败自动降级到自研引擎，不阻塞交互。
- 图 → molblock → `get_mol`（失败回退 SMILES 字符串）→ 读取描述符。
- 状态栏实时展示当前引擎（RDKit ✓ / 自研兜底）。

## 6. 状态管理设计

| Store | 职责 | 关键状态 |
|-------|------|----------|
| `moleculeStore` | 分子图与编辑编排 | `graph`、`past/future`（历史上限 50）、`hoverAtomId`、`selectedAtomId`、`connectFrom`、`pendingDelete`、`measure`、`arrangeParams` |
| `libraryStore` | 分子库 | `entries`（localStorage `molecule-library-v2`）、`loadedId` |
| `viewStore` | 画布视图 | `panX/panY`、`scale`（0.2–4）、`fit()` |

- **撤销/重做**：每次提交前将当前图深拷贝压入 `past`，重做栈清空。拖动入栈以「拖动快照」形式在拖动结束时提交一次，纯点击零位移不入栈。
- **选择与悬停分离**：悬停仅高亮，点选才出现工具条，避免误触。

## 7. 渲染设计

- 碳原子不渲染字母与圆，仅以键线交点表示；非碳原子/基团留出圆形空间，键线在圆周处截断。
- 双键/三键平行线间距分别为键长 1/5 与 3/4 倍该值。
- 热区与可见图形分离：原子热区半径 ≈ 0.6 倍键长（圆形），键热区宽度 ≈ 0.4 倍键长（矩形），导出时剔除热区。
- 官能团氢（-OH、-NH₂、-SH、-CHO 甲酰氢、端炔氢）由标签合并显示，不受「显示 C-H 氢」开关控制。

## 8. 构建与部署

```bash
npm install      # postinstall 自动执行 scripts/copy-rdkit.mjs
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # tsc -b && vite build → dist/
npm run preview  # 预览生产产物
```

- `scripts/copy-rdkit.mjs` 将 `node_modules/@rdkit/rdkit/dist` 下的 JS 胶水与 wasm 复制到 `public/rdkit/`，dev 与 build 均可访问。
- 构建目标 `es2022`，产物为纯静态资源，可部署到任意静态托管。
- **无后端依赖**：分子库存于浏览器 localStorage；命名在线源为可选的公共 API。

## 9. 边界情况与错误处理

| 情况 | 处理 |
|------|------|
| 价键超限 | 拒绝操作、Toast 报错、高亮相关原子 |
| 删除导致分子为空 | 自动重置为默认乙烷 |
| 删除环内键 | 开环处理，仅断开键、保留原子 |
| 芳香键用于非环结构 | 拒绝并提示改用单键 |
| 多分支删除 | 弹分支对话框，按 8 方位给出「保留左/右/上/下…」 |
| 画布边缘浮层溢出 | 工具条/菜单自动翻转并钳制在画布内 |
| RDKit 加载失败 | 状态栏显示「自研兜底」，命名仍可用 |
| 在线命名超时 | 5s 超时返回 null，命名降级但流程不阻塞 |
| InChIKey 重复 | 提示「该结构已在库中」并展示已有条目 |
| 命名失败 | 状态显示「命名失败，可手动输入」，允许编辑名称字段 |

## 10. 后续扩展方向

- 立体化学编辑：楔形键、R/S、E/Z（数据结构已预留字段）。
